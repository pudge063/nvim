# Команды `:` (Ex-команды) — от простого к сложному

Всё, что начинается с `:` (командная строка / command-line mode) —
это не хоткеи этого конфига, а сам vim, работает где угодно. Базовый
минимум есть и в [VIM-BASICS.md](VIM-BASICS.md#командная-строка), здесь —
полный разбор, от `:w` до батч-правки по десяткам файлов.

## Основы

| Команда | Значит |
|---|---|
| `:w` | Сохранить |
| `:w {путь}` | Сохранить как (не меняя имя текущего буфера) |
| `:q` | Закрыть окно (если последнее — выйти) |
| `:wq` / `:x` | Сохранить и закрыть (`:x` не пишет файл, если изменений не было) |
| `:q!` | Закрыть без сохранения |
| `:qa!` | Закрыть **всё**, не сохраняя нигде — осторожно |
| `:e {путь}` | Открыть файл |
| `:e!` | Перечитать текущий файл с диска, отбросив несохранённые правки |
| `:messages` | Последние сообщения/ошибки — если что-то мелькнуло и пропало |

## Диапазоны (ranges) — основа всего остального

Почти любая Ex-команда ниже принимает диапазон строк **перед** именем
команды: `:{диапазон}{команда}`. Без диапазона команда обычно
применяется только к текущей строке.

| Диапазон | Значит |
|---|---|
| (ничего) | Текущая строка |
| `.` | Текущая строка (явно) |
| `$` | Последняя строка файла |
| `%` | Весь файл (эквивалент `1,$`) |
| `5,10` | Строки с 5 по 10 |
| `.,+5` | От текущей строки на 5 вниз |
| `.,-3` | От текущей строки на 3 вверх (обычно пишут `-3,.`) |
| `'<,'>` | Выделение из последнего visual mode — подставляется само, если ввести `:` **находясь в visual mode** |
| `'a,'b` | От метки `a` до метки `b` (см. [VIM-BASICS.md](VIM-BASICS.md#метки-marks)) |
| `/foo/,/bar/` | От следующей строки, содержащей `foo`, до следующей с `bar` |

Практика: выделите строки в `V` (visual line), нажмите `:` — командная
строка сама подставит `:'<,'>`, дальше просто дописываете команду
(`sort`, `s/.../.../`, что угодно из этого файла).

## Поиск и замена: `:substitute`

```
:[диапазон]s/паттерн/замена/[флаги]
```

| Команда | Значит |
|---|---|
| `:s/old/new/` | Первое вхождение в текущей строке |
| `:s/old/new/g` | Все вхождения в текущей строке (`g` = global **для строки**, не для файла — частая путаница) |
| `:%s/old/new/g` | По всему файлу |
| `:%s/old/new/gc` | То же, но с подтверждением каждой замены: `y`/`n`/`a` (все)/`q` (стоп)/`l` (эта и стоп) |
| `:%s/old/new/gi` | Игнорировать регистр в поиске |
| `:'<,'>s/old/new/g` | Только в выделении (visual mode → `:`, диапазон подставится) |

**Разделитель не обязан быть `/`** — если паттерн сам содержит `/`
(например, путь), возьмите другой символ, он используется одинаково
во всех трёх частях: `:%s#old/path#new/path#g` или `:%s,old/path,new/path,g`.

**Группы захвата и обратные ссылки**: `\(...\)` в паттерне = группа,
`\1`, `\2`... в замене = ссылка на неё.
```
:%s/\(foo\) \(bar\)/\2 \1/
```
меняет местами `foo bar` → `bar foo` везде в файле.

**Спецсимволы в замене**: `&` = всё найденное совпадение целиком (без
групп), `\r` (не `\n`!) = разрыв строки, `\u`/`\U` = следующий
символ/весь остаток в верхний регистр, `\l`/`\L` = в нижний, `\e`/`\E` —
закрыть `\U`/`\L`.
```
:%s/^\w/\u&/
```
делает первую букву каждой строки заглавной.

**Вычисляемая замена** — `\=` интерпретирует остаток как Vimscript-
выражение:
```
:%s/^/\=line('.') . '. '/
```
пронумерует все строки (`1. `, `2. `, ...) — вычисляется заново для
каждой строки, `line('.')` — номер текущей на момент замены.

## Сортировка: `:sort`

**Не путать с shell `sort -u`** — у Ex-команды `:sort` **нет дефиса**,
флаги — это буквы сразу после имени команды: `:sort u`, а не `:sort -u`.

| Команда | Значит |
|---|---|
| `:sort` | Отсортировать весь файл по алфавиту |
| `:sort!` | То же, в обратном порядке |
| `:sort u` | Отсортировать и убрать дубликаты (`u` = unique) |
| `:sort n` | Сортировка по числовому значению, а не лексикографически (`10` после `2`, не перед) |
| `:'<,'>sort` | Сортировать только выделение (visual mode → `:`) |
| `:sort /паттерн/` | Сортировать по ключу — тому, что **после** совпадения паттерна в каждой строке, а не по всей строке |

Пример `:sort /паттерн/`: список вида `user_42: Alice`, `user_7: Bob` —
`:sort /.*: /` отсортирует по имени (Alice, Bob), проигнорировав
префикс `user_N: `.

## Глобальные команды: `:g` и `:v`

```
:[диапазон]g/паттерн/команда
```
Находит все строки, совпадающие с паттерном, и выполняет `команда` на
каждой (по умолчанию — `команда` = `p`, печать). `:v` (или `:g!`) —
то же самое, но для строк, **не** совпадающих с паттерном.

| Команда | Значит |
|---|---|
| `:g/^$/d` | Удалить все пустые строки |
| `:v/^$/d` | Удалить все НЕпустые строки (оставить только пустые) |
| `:g/TODO/d` | Удалить все строки с `TODO` |
| `:g/foo/s/bar/baz/g` | Замена `bar`→`baz`, но только в строках, где есть `foo` |
| `:g/pattern/m$` | Переместить все совпавшие строки в конец файла (сохраняя их относительный порядок) |
| `:g/pattern/t$` | Скопировать (не переместить) совпавшие строки в конец |
| `:g/foo/normal A;` | Дописать `;` в конец каждой строки, где есть `foo` (см. следующий раздел) |

`:g` + `normal` — самая мощная комбинация в этом файле: `:g` даёт
список строк по условию, `:normal` выполняет на каждой из них
произвольную normal-mode команду, включая макрос (`@a`).

## `:normal` — прогнать normal-mode команду по диапазону

```
:[диапазон]normal {команды}
```
(`:norm` — то же самое короче). Выполняет обычные normal-mode нажатия
клавиш на каждой строке диапазона, как будто вы их напечатали руками.

| Команда | Значит |
|---|---|
| `:%normal A;` | Добавить `;` в конец **каждой** строки файла |
| `:'<,'>normal I# ` | Закомментировать выделение (Python) — вставить `# ` в начало каждой строки |
| `:%normal @a` | Прогнать записанный макрос `a` на каждой строке файла |
| `:g/pattern/normal @a` | То же, но только на строках, совпавших с `pattern` — сочетание с предыдущим разделом |

Важно: `:normal` без диапазона выполняет команду один раз (на текущей
строке), с диапазоном — по разу **на каждой строке диапазона отдельно**
(курсор возвращается на начало строки перед каждым прогоном).

## Внешние команды шелла

| Команда | Значит |
|---|---|
| `:r !{команда}` | Вставить вывод команды шелла **после** текущей строки |
| `:.!{команда}` | Прогнать **текущую строку** через команду шелла, заменить её выводом |
| `:%!{команда}` | Прогнать **весь буфер** через команду, заменить содержимым вывода |
| `:'<,'>!{команда}` | То же самое, но только для выделения |

Примеры:
```
:%!sort -u                " тот же результат, что :sort u, но через shell sort
:%!jq .                   " красиво отформатировать JSON через jq
:%!column -t              " выровнять колонки, разделённые пробелами, в таблицу
:r !date                  " вставить текущую дату строкой
```
Разница `:%!` и `:%s`/`:sort`: `:%!` отдаёт буфер **внешней программе**
и полностью заменяет его выводом — годится для всего, что есть в виде
CLI-утилиты (в отличие от regex-замены, `:%!` может делать сколь угодно
сложную трансформацию, но требует, чтобы утилита была установлена).

## Строки: `:move`, `:copy`

| Команда | Значит |
|---|---|
| `:m +1` | Переместить текущую строку на 1 вниз |
| `:m -2` | Переместить на 1 вверх (`-2`, потому что считается ДО перемещения) |
| `:m 0` | Переместить в самое начало файла |
| `:m $` | Переместить в самый конец |
| `:'<,'>m +3` | Сдвинуть выделенные строки на 3 вниз |
| `:t .` (или `:co .`) | Скопировать (duplicate) текущую строку под собой |
| `:'<,'>t $` | Скопировать выделение в конец файла |

## `:argdo` / `:bufdo` — команда сразу по многим файлам

Обе выполняют команду по очереди в каждом файле списка, но списки
разные: `:argdo` — по файлам из **argument list** (`:args
**/*.py` наполняет его через glob), `:bufdo` — по всем **уже открытым
буферам**.

```
:args **/*.py
:argdo %s/foo/bar/ge | update
```
`%s/foo/bar/ge` — замена по всему каждому файлу (флаг `e` подавляет
ошибку «паттерн не найден», если в каком-то файле совпадений нет —
без него `:argdo` остановится на первом файле без совпадений),
`| update` — сохранить файл, только если он реально изменился (не
дёргает лишний раз `:w` на файлах без изменений).

## Готовые рецепты

| Задача | Команда |
|---|---|
| Заменить один символ на другой везде | `:%s/x/y/g` |
| Заменить все `'` на `"` | `:%s/'/"/g` |
| Заменить все `"` на `'` | `:%s/"/'/g` |
| Поменять `'` и `"` **местами** (одной операцией, без коллизии) | `:%s/['"]/\=submatch(0) == "'" ? '"' : "'"/g` — `\=` вычисляет замену Vimscript-выражением для каждого совпадения, поэтому не нужен временный символ-заглушка |
| Убрать пустые строки | `:g/^$/d` |
| Убрать висящие пробелы в конце строк | `:%s/\s\+$//e` (флаг `e` — не ругаться, если нигде не найдено) |
| Табы → пробелы (с учётом `shiftwidth`) | `:retab` |
| Отсортировать и убрать дубликаты строк | `:sort u` |
| Пронумеровать строки | `:%s/^/\=line('.') . '. '/` |
| Обернуть каждую строку выделения в `"..."` + запятая (список для кода) | `:'<,'>s/.*/"&",/` |
| Закомментировать выделение (Python) | `:'<,'>normal I# ` |
| Поменять местами два слова в каждой строке | `:%s/\(\w\+\) \(\w\+\)/\2 \1/` |
| Заменить `foo`→`bar` во всех `.py`-файлах проекта | `:args **/*.py` затем `:argdo %s/foo/bar/ge \| update` |

Более простую однократную замену (без regex, без диапазонов) часто
быстрее сделать текстовым объектом (`ciw`, `ci"`) — см.
[VIM-BASICS.md](VIM-BASICS.md#операторы--текстовые-объекты). Ex-команды
из этого файла нужны, когда правка не «в одном месте», а по всему
файлу/проекту сразу.
